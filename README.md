# SmartCare Hospital — Static Hackathon Website

A minimal, light-theme static website concept for the GNDEC hackathon.

## What is included

- Responsive landing page
- Smart triage concept
- Appointment and queue concept
- Connected health records
- Patient journey / workflow
- Follow-up care
- Sample doctor-facing health record
- Static appointment demo
- No backend
- No database
- No external libraries
- No API calls

## Run

Just open `index.html` in a browser.

For the hackathon, you can later connect the same UI to a Flask/Python backend if your team decides to make the demo functional.

All patient information shown is fictional demo data.
